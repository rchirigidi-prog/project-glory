# Purpose

This document defines the visual language of SingThyGlory Studio.

Every page, module, component, and future feature must follow this design system to ensure a consistent user experience.

---

# Design Principles

Our design should be:

- Christ-centered
- Clean
- Professional
- Accessible
- Fast
- Responsive
- Modern without being distracting

The focus should always remain on worship, God's Word, prayer, and ministry.

# Coding Standards

## PHP

- PSR-12
- One class per file
- One responsibility per class

## HTML

- Semantic HTML5
- Bootstrap 5

## CSS

- Components only
- Reusable classes

## JavaScript

- Vanilla JS where possible
- Modular

## Project Rules

No duplicated code

No duplicated layouts

No hard-coded URLs

No hard-coded asset paths

Always use helper functions

Always use configuration

Always test before commit
